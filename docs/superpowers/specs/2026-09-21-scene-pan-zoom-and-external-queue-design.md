# 关卡场景平移缩放与外置候场区设计

## 目标

修复候场区被遮挡的问题，并为关卡场景编辑画布提供左键拖动平移、滚轮缩放功能。

## 范围与约束

- 编辑器候场区位于手机容器上方，作为手机容器的兄弟元素；完整展开且不被手机边框裁切。
- 手机容器内部只显示 HUD、背景和棋盘；棋盘布局不依赖任何候场区变量。
- 外置候场区与棋盘使用完全相同的宽度和列网格；每列底部切片紧贴手机上边缘。
- 左键仅在画布空白区域拖动时平移整个编辑器场景组合。
- 点击棋盘或候场切片仍执行既有预选/交换，不产生平移。
- 滚轮在指针位置缩放编辑器场景组合，缩放范围为 50% 至 200%。
- 运行预览保持静态，不加入编辑器的平移缩放交互。
- 不修改关卡数据、切片顺序、资源路径或现有交换逻辑。

## 布局方案

`#scene-composition` 和 `#runtime-composition` 使用纵向组合布局：候场区在上、手机在下。组合容器的宽度来自棋盘宽度，高度来自“候场高度 + 间距 + 手机高度”，再由其所在舞台居中定位。手机的 `overflow: hidden` 只作用于手机内部，因此不会裁切外置候场区。

棋盘在手机的 HUD 下方、手机剩余可用空间内居中。候场列的高度、切片高度和相邻切片间距只读取外置队列变量；编辑器步长等于切片高度，运行预览步长小于切片高度。

## 交互方案

编辑器状态新增 `sceneViewport`：`{ x, y, zoom }`。渲染时将它映射为组合容器的 CSS 变换变量。画布监听 Pointer Events：主按钮在非交互子元素上开始时记录指针与原始偏移；移动时更新 `x/y`；释放或取消时结束拖动。画布监听非被动 `wheel` 事件，阻止页面滚动，基于鼠标相对画布的位置调整偏移，使缩放焦点保持在指针下方。

缩放初始值为 1，限制到 0.5–2；每次滚轮按固定比例调整。切片、按钮、选择器和其他可交互元素通过最近交互元素判断排除平移起点。

## 模块边界

- `editor-state.mjs`：创建、归一化和更新 `sceneViewport` 的纯函数；可独立测试缩放限制和以指针为中心的偏移计算。
- `app.mjs`：监听编辑画布指针和滚轮，调用状态函数，写入组合容器 CSS 变量；不改变运行预览交互。
- `index.html`：为场景画布和缩放显示提供稳定 ID/可访问说明。
- `styles.css`：组合容器布局、外置队列布局、手机内棋盘布局，以及拖动时的光标反馈。
- `editor-state.test.mjs`：覆盖 viewport 初始状态、平移和边界缩放。

## 错误处理

无效坐标、比例或缩放值使用安全默认值；所有视图状态始终返回有限数值。指针取消会清除拖动会话，避免画布停留在拖动状态。

## 验证

1. 新增失败测试，验证缩放被限制在 0.5–2 且指针缩放会相应更新偏移。
2. 检查关卡 1、15、21、24、27、30：候场区完整显示在手机上方，手机内部无候场 DOM，候场列与棋盘列对齐。
3. 浏览器验证：左键拖空白画布可移动组合；点击切片保持选择行为；滚轮缩放保持鼠标焦点且不滚动页面。
4. 运行完整 Node 测试和浏览器控制台错误检查。
